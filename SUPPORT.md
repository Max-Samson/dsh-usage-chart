# Support

## Before opening an issue

Check the README installation and verification steps, then run `npm run verify` in a
clean checkout when you can reproduce a problem locally.

## Where to ask

- **Bug or reproducible regression:** open a GitHub bug report and include DSH, plugin,
  Node.js, browser, and operating-system versions.
- **Feature idea:** open a feature request and explain the DSH workflow it improves.
- **Security concern:** use GitHub private vulnerability reporting as described in
  [SECURITY.md](./SECURITY.md). Do not create a public issue.

Please redact API keys, session content, account balances, costs, and logs before
sharing any diagnostic material.
